# 语音驱动智能跟拍机器人——PPT 展示大纲

> 建议页数：9 页  
> 建议时长：12～14 分钟  
> 展示重点：突出系统能完成什么，技术原理只保留必要关键词。

## 第 1 页：语音驱动的智能跟拍机器人

**副标题：** 从一句自然语言到自主跟随与运镜

- 语音理解拍摄意图。
- 视觉持续锁定人物。
- 云台与底盘协同运动。
- 开发电脑远程查看运行状态。

**画面建议：** 使用机器人实机照片，标出 Sony 相机、深度相机、DJI RS2、Jetson 和底盘。

## 第 2 页：机器人把“说人话”变成实际拍摄动作

典型指令：

- “开始跟随我，保持两米距离。”
- “进入运镜，向前推进一米。”
- “镜头向上一点。”
- “紧急停止。”

完整响应过程：

```text
听懂指令 → 找到人物 → 保持构图 → 调整距离 → 执行动作 → 返回状态
```

**功能亮点：** 用户不需要记忆固定控制格式，可以直接表达拍摄需求。

## 第 3 页：四个模块组成完整闭环

```text
语音指令识别
自然语言 → 结构化任务
        ↓
视觉感知
人物检测 → ID 跟踪 → 2D/3D 目标
        ↓
伺服控制
云台快速构图 + 底盘距离控制
        ↓
软硬件执行
Jetson → DJI RS2 + 全向底盘
        ↑
远程监控与状态反馈
```

**核心观点：** 项目不是多个独立功能的组合，而是一条从人机交互到机器人执行的闭环。

## 第 4 页：语音模块不仅识别文字，还能理解任务

主要能力：

- 覆盖移动、云台、跟随、运镜、录制、停止、查询等指令。
- 支持一句话包含多个动作。
- 根据待机、跟随、运镜状态消除语义歧义。
- 自动提取方向、距离、速度等参数。
- 低置信度、状态冲突和含糊指令默认不执行。

技术关键词：

```text
Qwen3-ASR · BERT · 双 SVM · 多意图分割 · LLM 参数抽取 · HTTP/ROS 2 桥接
```

**功能亮点：** Windows 负责语音前端，Jetson 保留最终验证和安全控制权，语音误识别不会直接驱动硬件。

---

## 第 5 页：视觉模块回答“是谁、在哪里、离多远”

主要能力：

- 实时检测画面中的人物。
- 为多个人物分配并保持 Tracking ID。
- 人脸优先，上半身和人体中心作为构图兜底。
- 短时遮挡时预测运动并尝试恢复原 ID。
- 融合深度相机，输出目标 X/Y/Z、距离和可信度。
- 深度暂时失效时，云台仍可依据二维画面继续追人。

技术关键词：

```text
Sony CRSDK · YOLOv8n TensorRT · ByteTrack · Kalman · Hungarian · 双相机标定与深度融合
```

**画面建议：** 放置 Foxglove 实机画面，展示人物框、ID、关注点和 XYZ 距离。

---

## 第 6 页：双环控制让镜头跟得快，机器人走得稳

控制分工：

- **二维云台快环：** 快速修正人物在画面中的水平和垂直偏差。
- **PBVS 底盘慢环：** 保持约 2 米距离，并在云台偏转较大时带动底盘回中。
- **统一命令仲裁：** 手动、语音、自主跟随和急停不会互相争抢执行器。

降级行为：

```text
2D、3D 均有效 → 云台与底盘协同
只有 2D 有效   → 云台继续跟踪，底盘停止平移
目标完全丢失   → 短时预测，随后安全停止
```

技术关键词：

```text
2D 视觉伺服 · PBVS · 运动预测 · 滤波 · 死区 · 限速 · command_mux
```

**功能亮点：** 将“快速构图”和“稳定移动”分开处理，避免深度波动拖慢云台响应。

---

## 第 7 页：跟随、遥控、微调和运镜统一管理

当前运行模式：

- **待机：** 等待下一项任务。
- **自动跟随：** 锁定人物并保持构图与距离。
- **连续遥控：** 人工控制底盘和云台。
- **手动微调：** 移动固定距离或调整固定角度，完成后自动回待机。
- **运镜模式：** 连续接受拍摄动作，退出后回到待机。

四种运镜能力：

- `STATIC_TRACK`：底盘不动，云台锁定人物。
- `DOLLY_IN_OUT`：向前推进或向后拉开。
- `TRUCK_LEFT_RIGHT`：左右横移跟拍。
- `ORBIT_ARC`：围绕人物完成限定角度环绕。

**功能亮点：** 所有模式共享统一状态机，支持动作取消、模式切换和紧急停车。

## 第 8 页：软硬件系统已经形成实机闭环

硬件连接：

```text
Sony ZV-E10 II ─ USB/CRSDK ─┐
Gemini 335 ───── USB ───────┤
                             ▼
                       Jetson Orin Nano
                          │        │
                 USB-CAN/1 Mbps   USB 串口
                          │        │
                       DJI RS2   三全向轮底盘

Windows 笔记本 ─ Wi-Fi/HTTP ─→ 语音指令
Windows/手机 ─ WebSocket ───→ Foxglove 监控
```

工程能力：

- ROS 2 Humble 模块化通信。
- 一键启动感知、控制、语音和监控链路。
- 自动识别并配置 USB-CAN 接口。
- Foxglove 远程显示视频、目标状态和性能指标。
- diagnostics、watchdog 和 rosbag 支持故障定位。

**功能亮点：** Jetson 独立完成实时闭环，电脑和手机只承担交互与远程观察。

## 第 9 页：项目实现了从“听见”到“完成拍摄”的闭环

项目特色总结：

1. **自然交互：** 使用日常语言控制机器人，不依赖专业遥控操作。
2. **双相机分工：** Sony 提供高质量画面，Gemini 提供三维距离。
3. **稳定跟踪：** 检测、ID 跟踪、关注点选择和深度融合连续工作。
4. **协同控制：** 高灵敏云台与稳定底盘分别承担构图和位置控制。
5. **多种拍摄方式：** 支持跟随、遥控、微调、推拉、横移和环绕。
6. **安全可观察：** 指令过滤、质量门控、统一仲裁、急停和远程监控贯穿全链路。

**结束语：**

> 这不仅是一台会跟人的机器人，更是一套能够理解拍摄意图、保持视觉构图并自主完成镜头运动的智能跟拍系统。
