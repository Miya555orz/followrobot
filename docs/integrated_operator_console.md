# FCR 实机集成控制台

控制台将完整实机节点放在后台运行，并在当前终端提供唯一的人工控制入口。

```text
1 STANDBY
2 FOLLOW
3 CINEMATIC_READY
4 MANUAL_JOG（执行一次后自动回 STANDBY）
5 TELEOP
```

## 启动

```bash
ros2 run bringup_pkg start_fcr_console.sh --controller pbvs
```

`Ctrl-C` 会先发送安全停车指令，再关闭完整实机 launch。

## 全局按键

| 按键 | 功能 |
|---|---|
| `1` | 停止当前任务并回待机 |
| `2` | 退出运镜/微调并进入自动跟随 |
| `3` | 停止跟随并进入运镜待命 |
| `4` | 停止当前自动任务，等待一次微调 |
| `5` | 停止自动任务并进入连续遥控 |
| `X` | 软件急停 |
| `C` | 清除软件急停请求 |
| `H` | 显示帮助 |

## 连续遥控

- `W/S` 前后，`A/D` 横移，`Q/E` 旋转。
- 方向键控制云台。
- 持续移动需要重复按键；松开后自动停车。
- 空格停车，`+/-` 调整速度倍率。

## 单次微调

按 `4` 后：

- `W/S/A/D`：底盘移动 10 cm。
- `Q/E`：底盘旋转 5°。
- 方向键：云台旋转 5°。

动作完成、取消或超时后自动回到 `STANDBY`，不会恢复之前的跟随或运镜。

## 运镜

按 `3` 进入运镜待命后：

- `Z`：STATIC_TRACK。
- `W/S`：DOLLY_IN_OUT 前/后方向。
- `A/D`：TRUCK_LEFT_RIGHT 左/右方向。
- `Q/E`：ORBIT_ARC 左/右方向。
- 运镜执行中直接按另一动作键：平滑停止当前动作并切换到新动作。
- 空格：只停止当前动作，继续保持 `CINEMATIC_READY`。

动态运镜的截止时间按运动量自动计算：

```text
超时 = max(12秒, 理论运动时间 × 1.8 + 5秒)
```

推拉采用相对当前深度的目标：`W` 靠近0.5m，`S` 远离0.5m。

动作结束后保持在 `CINEMATIC_READY`，可以继续发送下一条运镜动作；按 `1` 才退出。
